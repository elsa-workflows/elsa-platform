# Contract: Runtime Operations API

## GET /api/workspaces/{workspaceId}/managed-runtimes/{id}/health

Returns health summary.

## GET /api/workspaces/{workspaceId}/managed-runtimes/{id}/logs

Returns recent redacted logs.

## POST /api/workspaces/{workspaceId}/managed-runtimes/{id}/backups

Creates backup.

## POST /api/workspaces/{workspaceId}/managed-runtimes/{id}/restores

Restores backup.

## POST /api/workspaces/{workspaceId}/managed-runtimes/{id}/upgrades

Creates or applies upgrade plan.
