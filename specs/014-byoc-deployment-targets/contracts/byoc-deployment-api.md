# Contract: BYOC Deployment Targets API

## POST /api/workspaces/{workspaceId}/deployment-targets

Registers a target.

## POST /api/workspaces/{workspaceId}/deployment-targets/{targetId}/validate

Validates connectivity.

## POST /api/workspaces/{workspaceId}/deployment-previews

Creates preview for configuration/version and target.

## POST /api/workspaces/{workspaceId}/deployments

Starts deployment run.

## GET /api/workspaces/{workspaceId}/deployments/{runId}

Returns status and events.
