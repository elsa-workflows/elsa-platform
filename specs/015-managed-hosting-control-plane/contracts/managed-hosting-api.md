# Contract: Managed Hosting API

## POST /api/workspaces/{workspaceId}/managed-runtimes

Provision from configuration version.

## GET /api/workspaces/{workspaceId}/managed-runtimes

List environments.

## GET /api/workspaces/{workspaceId}/managed-runtimes/{id}

Get status, URL, and health.

## POST /api/workspaces/{workspaceId}/managed-runtimes/{id}/restart

Restart runtime.

## POST /api/workspaces/{workspaceId}/managed-runtimes/{id}/stop

Stop runtime.

## DELETE /api/workspaces/{workspaceId}/managed-runtimes/{id}

Delete runtime.
