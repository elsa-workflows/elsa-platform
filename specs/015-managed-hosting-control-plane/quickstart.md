# Quickstart: Managed Hosting Control Plane

1. Create saved configuration version.
2. Provision managed runtime.
3. Poll status until ready or failed.
4. Fetch URL and health.
5. Restart, stop, and delete runtime.

```bash
dotnet build Elsa.PackageCatalog.sln --no-restore
dotnet test Elsa.PackageCatalog.sln --no-build
```
