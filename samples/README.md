# Elsa Platform Samples

These samples show host wiring for the artifact-driven workflow path.

- [Platform-integrated Studio](platform-integrated-studio/README.md): enables **Submit to Platform** in Elsa Studio.
- [Workflow runtime applier](workflow-runtime-applier/README.md): enables an Elsa Workflows runtime to poll Platform commands and apply workflow artifacts.

The samples are intentionally host-focused. They show package registration, configuration shape, and host-owned extension points without adding runnable application templates yet.

Use these samples with the E2E smoke path in [Platform Artifact Workflow E2E Smoke](../docs/platform-artifact-workflow-e2e-smoke.md).
